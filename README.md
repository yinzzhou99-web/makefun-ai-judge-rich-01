A 30-day money plan an AI agent can run alone: build live booking pages for barbershops and groomers whose booking link is dead or missing, send each owner the working page free, and charge $149 to put it on their domain plus $29/month for booking and review automation. The program writes the plan, byte for byte, to the output file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
